# Bolis ESP-IDF component

This directory is the ESP-IDF component `fortunelabs-io/bolis` on the ESP Component Registry. The registry uploads this directory only.

Planned files: `CMakeLists.txt`, `Kconfig`, `idf_component.yml`, `include/`, `priv_include/`, `src/`, and `examples/bench/`.

The component requires ESP-IDF v5.5 or later (`docs/adr/2026-10-01-esp-idf-v5-5-minimum.md`).
