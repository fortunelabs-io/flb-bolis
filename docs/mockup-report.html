Origin labels

A value computed only from measured values.

What replaces this pageThe repository shows this page until a verification pair passes. A pair is two runs on one bench and one declared geometry, with both nodes removed and placed again between them, and the second run on a later calendar day. The pair passes when the baseline loss intervals of the two runs overlap and the lists of variables that moved loss are identical.
